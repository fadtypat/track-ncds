ผู้ป่วยทั้งหมดในระบบ (มุมมอง Admin)

Admin เห็นผู้ป่วยทุกรายในระบบโดยไม่ต้องมี PatientAssignment เป็นของตนเอง (ข้อยกเว้นจาก NFR-02 ตาม NFR-19) เพื่อสนับสนุนงานบริหารจัดการเท่านั้น — การเปิดดูประวัติแต่ละราย เป็นแบบอ่านอย่างเดียว (FR-15) และทุกครั้งที่เข้าถึงระบบจะบันทึก audit log แบบ fail-safe ก่อนเสมอ (NFR-20)

มุมมอง Admin: ไม่จำกัดด้วย PatientAssignment (NFR-19)
