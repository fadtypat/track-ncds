ปัจจัยเสี่ยงที่พบ
  • eGFR ลดลงต่อเนื่อง 3 visit ล่าสุด (68 → 52 → 41 mL/min/1.73m²)
  • HbA1c สูงกว่าเกณฑ์ต่อเนื่องและมีแนวโน้มแย่ลง (7.8 → 8.5 → 9.2%)
  • ควบคุมความดันโลหิตได้ไม่ดีต่อเนื่องหลายครั้ง
คำแนะนำเชิงระบบ
  • พิจารณาส่งปรึกษาอายุรแพทย์โรคไต (Nephrology referral)
  • ทบทวนแผนการรักษาเบาหวานเพื่อควบคุม HbA1c ให้เข้าเกณฑ์
  • ติดตาม eGFR และความดันโลหิตซ้ำในรอบ 3 เดือน
หมายเหตุ threshold

ค่า threshold ตัวเลขที่ใช้ตัดสินระดับความเสี่ยงข้างต้นยังไม่ได้รับการยืนยันจากผู้เชี่ยวชาญ (ดู DESIGN.md §2.3 และ spec ต้นทาง หัวข้อสมมติฐาน) ตัวเลข % ในหน้านี้เป็นข้อมูล mockup สำหรับสาธิตการแสดงผลเท่านั้น
