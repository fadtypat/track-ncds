ประวัติโรค NCD ผลตรวจ Lab และการวิเคราะห์ความเสี่ยงโรคแทรกซ้อน

Prototype เวอร์ชัน v1 ของฟีเจอร์ตาม 20260917-01-patient-ncd-history-lab-complication-risk และ 20260921-01-pdpa-data-protection-compliance ครอบคลุมทั้ง 4 ฟีเจอร์ Must have ใน feature-list.md สำหรับผู้ใช้บทบาทเดียว: แพทย์/พยาบาลผู้ดูแลผู้ป่วย NCD

บทบาทผู้ใช้: แพทย์/พยาบาลผู้ดูแลผู้ป่วย NCD (NFR-02)

Journey ที่ 1 — routine การดูแลผู้ป่วย (ฟีเจอร์ 1–3)

อ้างอิง user-journey.md — ลำดับ: ตรวจสิทธิ์ → ค้นหา/เลือกผู้ป่วย → ดูประวัติ+lab → วิเคราะห์ความเสี่ยง
  1. 1. ระบบตรวจสอบสิทธิ์การเข้าถึง ถ้าไม่มีสิทธิ์ หรือผู้ป่วยไม่ได้อยู่ในความดูแล → ปฏิเสธการเข้าถึง
    เปิดหน้าปฏิเสธการเข้าถึง NFR-02
  2. 2. ค้นหา/เลือกผู้ป่วยในความดูแล ค้นหาด้วยเลข HN 7 หลัก หรือเรียกดูรายชื่อทั้งหมดที่อยู่ในความดูแล
    เปิดหน้ารายชื่อผู้ป่วย FR-05·FR-06
  3. 3. ดูประวัติวินิจฉัย + ผลตรวจ lab ย้อนหลัง + ผลวิเคราะห์ความเสี่ยง (พบความเสี่ยง) ตัวอย่างผู้ป่วยที่ระบบ flag ความเสี่ยงโรคแทรกซ้อนสูง/สูงมาก
    เปิดตัวอย่าง (พบความเสี่ยง) FR-01·FR-02·FR-03·FR-04
  4. 3b. ดูประวัติวินิจฉัย + ผลตรวจ lab ย้อนหลัง + ผลวิเคราะห์ความเสี่ยง (ไม่พบความเสี่ยง) ตัวอย่างผู้ป่วยที่ไม่พบความเสี่ยงเกิน threshold — แขนง "ไม่พบ" ของ FR-04
    เปิดตัวอย่าง (ไม่พบความเสี่ยง) FR-01·FR-02·FR-03·FR-04

Journey ที่ 2 — คำขอใช้สิทธิของเจ้าของข้อมูล และสนับสนุนการสืบสวนข้อมูลรั่วไหล (PDPA, ฟีเจอร์ 4)

Trigger จากเหตุการณ์ภายนอก (ไม่ใช่ routine การดูแลผู้ป่วย) — แยก 2 เส้นทางตามประเภทเหตุการณ์
  1. 2ก. ได้รับคำขอใช้สิทธิของเจ้าของข้อมูล (ผู้ป่วย) ค้นหาผู้ป่วยด้วย HN (Operation 0, ใช้หน้าค้นหา/รายชื่อผู้ป่วยร่วมกัน) → เลือกประเภทคำขอ (เข้าถึง/สำเนา/แก้ไข/ลบ/คัดค้าน) → ดำเนินการ
    เปิดหน้าคำขอใช้สิทธิ PDPA NFR-03·NFR-05·NFR-06·NFR-07
  2. 2ข. สงสัยว่ามีเหตุข้อมูลส่วนบุคคลรั่วไหล สืบค้น audit log (ระบุผู้ป่วย/ช่วงเวลา/ผู้ใช้ — ไม่บังคับ) เพื่อสนับสนุนการสืบสวน/แจ้งเหตุละเมิด
    เปิดหน้าสืบค้น audit trail NFR-02·NFR-06·NFR-08
