**บริบท**

ผู้ใช้ต้องการให้หน้า `patient-list.html` ใน prototype
`01-prototypes/20260922-01-firestore-demo/` อ่านรายชื่อผู้ป่วยจาก Firestore เมื่อตรวจโค้ดก่อนลงมือ
พบว่าหน้านี้อ่านจาก collection `patients` อยู่แล้ว (ตรงกับ [[db-spec]]) และไม่มีข้อมูลผู้ป่วย hardcode
ในไฟล์ ผู้ใช้ยืนยันว่าหมายถึง collection `patients` ตัวเดิม จึง**ไม่ได้แก้โค้ด** มีแค่การตรวจสอบการทำงาน
จริงในเบราว์เซอร์เท่านั้น

**วิธีตรวจสอบ**

- เปิดผ่าน static server ในเครื่อง (`.claude/launch.json` → `docs-static`, `http-server docs -p 4873`)
  เพราะเปิดไฟล์ผ่าน `file://` โดยตรงแล้วสคริปต์ Firebase ไม่ทำงาน
- ใช้หน้า `http://localhost:4873/02-design/01-prototypes/20260922-01-firestore-demo/patient-list.html`

**ผลการตรวจสอบ** — ผ่านทุกข้อ

| รายการ | ผล |
|---|---|
| โหลดข้อมูลจาก Firestore | สำเร็จ 30 ราย แสดงการ์ดครบ 30 ใบ |
| ความครบถ้วนของการ์ด | ไม่มีค่า `undefined`/`null`/`NaN` และ HN เป็นตัวเลข 7 หลักทุกใบ (FR-06) |
| ตัวเลขสรุป | ทั้งหมด 30 คน · เสี่ยงสูง/สูงมาก 22 คน · อยู่ในระยะ CKD 0 คน |
| ค้นหา HN ที่มีอยู่จริง (FR-06) | พบการ์ดผู้ป่วย |
| ค้นหา HN รูปแบบผิด (`12ab`) | แสดงข้อความให้กรอกตัวเลข 7 หลัก |

| ลิงก์ "เปิดประวัติ" | ไปที่ `patient-detail.html?id=…` แล้วโหลดข้อมูลจาก Firestore สำเร็จ |
| Console | หน้ารายชื่อไม่มี error · หน้าประวัติมี error เครือข่ายชั่วคราว 1 ครั้ง (`QUIC_NETWORK_IDLE_TIMEOUT`) แต่ข้อมูลยังโหลดครบ |
