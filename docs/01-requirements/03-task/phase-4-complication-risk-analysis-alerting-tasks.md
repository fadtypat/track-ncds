# Phase 4 — วิเคราะห์/แจ้งเตือน/ยืนยันแก้ไขผลประเมินความเสี่ยง + Admin ดูข้อมูลผู้ป่วยทุกรายแบบอ่านอย่างเดียว: งานย่อย

ส่วนหนึ่งของ [[release-plan]] (Phase 4) ครอบคลุม FR-03, FR-04, FR-15, FR-16, NFR-11, NFR-19, NFR-20
จาก [[backlog]] รวม [[feature-list#2. วิเคราะห์ แจ้งเตือน และยืนยัน/แก้ไขผลประเมินความเสี่ยงโรคแทรกซ้อน|feature-list ฟีเจอร์ที่ 2]]
ทั้งหมด และส่วนดูข้อมูลผู้ป่วยทุกรายของ
[[feature-list#7. จัดการบัญชีผู้ใช้งานและสิทธิ์ (Admin)|feature-list ฟีเจอร์ที่ 7]]
(เฉพาะ FR-15/NFR-19/NFR-20 — ส่วน FR-11–FR-13 ของฟีเจอร์เดียวกันอยู่ที่
[[phase-1-authentication-tasks|Phase 1]] แล้ว) งานย่อยด้านล่างเขียนด้วยภาษาเชิงพฤติกรรม/ผลลัพธ์เท่านั้น
**ไม่ระบุเทคโนโลยีการ implement** ต้องเริ่มหลัง [[phase-3-ncd-diagnosis-lab-history-tasks|Phase 3]]
เสร็จสมบูรณ์ (ต้องมีข้อมูลผลตรวจ lab ในระบบก่อนจึงวิเคราะห์ความเสี่ยงได้ และ Admin ต้องมีทั้งประวัติ
วินิจฉัย/ผล lab จาก Phase 3 พร้อมผลวิเคราะห์ความเสี่ยงของ phase นี้เองครบก่อนจึงดูข้อมูลผู้ป่วยทุกราย
ได้อย่างมีความหมาย)

**หมายเหตุอัปเดต 2026-09-28:** ระบบยกเลิกกลไก PatientAssignment ทั้งหมดตั้งแต่ 2026-09-25 (ดู
[[backlog]] — FR-14 ยกเลิกแล้ว) FR-16 จึงครอบคลุมผู้ป่วย**ทุกราย**ในระบบ (ไม่จำกัดเฉพาะผู้ป่วยที่เคย
"อยู่ในความดูแล" อีกต่อไป) และ NFR-19 ไม่ใช่ "ข้อยกเว้น" จาก NFR-02 อีกต่อไปเช่นกัน (การเห็น/เข้าถึง
ผู้ป่วยทุกรายเป็นบรรทัดฐานของทุกบทบาทอยู่แล้ว) สิ่งที่ยังคงเป็นลักษณะเฉพาะของ Admin คือสิทธิ์**อ่าน
อย่างเดียว**และ audit log แบบ fail-safe ตาม NFR-20 เท่านั้น T-4-06/T-4-08/T-4-09 ด้านล่างแก้ถ้อยคำให้
ตรงกับนิยามนี้แล้ว

| รหัส | ชื่องาน | FR/NFR ที่เกี่ยวข้อง | หมายเหตุ dependency ภายใน phase |
| --- | --- | --- | --- |
| T-4-01 | กำหนด/จัดเตรียมเกณฑ์ (threshold) ค่า lab มาตรฐานที่ใช้ประเมินความเสี่ยงโรคแทรกซ้อนแต่ละชนิดในขอบเขต (ไตวายเรื้อรัง, โรคหัวใจ, โรคหลอดเลือดสมอง) | FR-03 | ไม่มี — เป็นจุดเริ่มต้นของ phase |
| T-4-02 | ยืนยันความถูกต้องของการจับคู่โรคหลัก→โรคแทรกซ้อนและ threshold ค่า lab ที่ใช้ โดยแพทย์ผู้เชี่ยวชาญ ก่อนนำไปใช้งานจริงทุกครั้ง (รวมถึงทุกครั้งที่มีการปรับปรุงเกณฑ์ในอนาคต) | NFR-11 | ต่อจาก T-4-01 (ต้องยืนยันก่อนเริ่มใช้งานจริง และก่อนปรับปรุงเกณฑ์ครั้งถัดไปทุกครั้ง) |
| T-4-03 | ประมวลผลค่า lab ของผู้ป่วยรายบุคคลเทียบกับเกณฑ์ที่ยืนยันแล้ว เพื่อประเมินความเสี่ยงการเกิดโรคแทรกซ้อนแบบ rule-based | FR-03 | ต่อจาก T-4-02 |
| T-4-04 | แสดงผลการประเมินความเสี่ยงเป็น flag/สัญญาณเตือนที่มองเห็นได้ชัดเจนบนหน้าจอของผู้ดูแล ต่อผู้ป่วยรายบุคคล เพื่อสนับสนุนการตัดสินใจทางคลินิก | FR-04 | ต่อจาก T-4-03 |
| T-4-05 | แสดงข้อความที่ชัดเจนเมื่อผลการประเมินไม่พบความเสี่ยง (ไม่ปล่อยว่างเปล่าหรือคลุมเครือ) | FR-04 | ต่อจาก T-4-03 |
| T-4-06 | แพทย์/พยาบาลทุกคน (ต่อผู้ป่วย**ทุกราย**ในระบบตาม NFR-02 ที่แก้ไข 2026-09-25) ยืนยันหรือแก้ไข (override) ผลการประเมินความเสี่ยงที่ระบบประมวลผลอัตโนมัติ | FR-16 | ต่อจาก T-4-04 |
| T-4-07 | บันทึกร่องรอยการเข้าถึง (audit log) ทุกครั้งที่มีการยืนยัน/แก้ไขผลประเมินความเสี่ยง | FR-16 | ต่อจาก T-4-06 |
| T-4-08 | ผู้ดูแลระบบ (Admin) เปิดดูประวัติการวินิจฉัย ผลตรวจ lab และผลวิเคราะห์ความเสี่ยงโรคแทรกซ้อนของผู้ป่วย**ทุกราย**ในระบบแบบอ่านอย่างเดียว | FR-15 | ต่อจาก T-4-03 (ต้องมีผลวิเคราะห์ความเสี่ยงในระบบก่อน) และหลัง [[phase-3-ncd-diagnosis-lab-history-tasks|Phase 3]] เสร็จสมบูรณ์ (ต้องมีประวัติวินิจฉัย/ผล lab ก่อนด้วย) |
| T-4-09 | จำกัดสิทธิ์ Admin ให้เข้าถึงข้อมูลผู้ป่วยได้เฉพาะแบบอ่านอย่างเดียวเท่านั้น (ไม่มีสิทธิ์แก้ไขประวัติวินิจฉัย ผล lab หรือผลวิเคราะห์ความเสี่ยงใดๆ — สิทธิ์แก้ไข/ยืนยันผลวิเคราะห์ความเสี่ยงยังคงเป็นของแพทย์/พยาบาลตาม T-4-06 เท่านั้น) | NFR-19 | ต่อจาก T-4-08 |
| T-4-10 | บันทึกร่องรอยการเข้าถึงข้อมูลผู้ป่วยของ Admin แบบ fail-safe ทุกครั้ง (บันทึก log ก่อนคืนข้อมูลเสมอ หากบันทึกไม่สำเร็จต้องปฏิเสธการเข้าถึงทันที) | NFR-20 | ต่อจาก T-4-08 |
