# Phase 3 — ดูประวัติวินิจฉัยและผลตรวจ lab + AI สรุปการตรวจ HbA1c รายปีงบประมาณ: งานย่อย

ส่วนหนึ่งของ [[release-plan]] (Phase 3) ครอบคลุม FR-01, FR-02, FR-18, NFR-01 จาก [[backlog]] และ
[[feature-list#1. ดูประวัติการวินิจฉัยและผลตรวจ lab ของผู้ป่วย NCD|feature-list]] งานย่อยด้านล่างเขียน
ด้วยภาษาเชิงพฤติกรรม/ผลลัพธ์เท่านั้น **ไม่ระบุเทคโนโลยีการ implement** ต้องเริ่มหลัง
[[phase-2-patient-search-selection-data-protection-foundation-tasks|Phase 2]] เสร็จสมบูรณ์ (ต้องเลือก
ผู้ป่วยรายบุคคลได้ก่อนจึงจะดูประวัติได้)

**หมายเหตุอัปเดต 2026-09-28:** (1) เพิ่ม T-3-05–T-3-07 (FR-18 — รหัสใหม่จาก requirement ดิบเรื่อง AI
สรุปจำนวนครั้งตรวจ HbA1c/ระยะห่างระหว่างการตรวจในปีงบประมาณ รายผู้ป่วย) ต่อยอดจาก T-3-03 (FR-02) เพราะ
ต้องมีข้อมูลผล lab ในระบบก่อนจึงคำนวณสรุปได้ แม้ปุ่มเรียกใช้งานจะอยู่บนหน้าจอรายชื่อผู้ป่วยของ
[[phase-2-patient-search-selection-data-protection-foundation-tasks|Phase 2]] (FR-05) ก็ตาม — ข้อมูลที่
ส่งให้บริการ AI ภายนอกในงานนี้จำกัดตาม NFR-21 เช่นเดียวกับ T-2-09 (คนละชุดข้อมูล: เฉพาะตัวเลขสรุปที่
คำนวณแล้ว ไม่ใช่ HN/สถานะการค้นหา) **หมายเหตุช่องว่างเอกสาร:** [[feature-list]] ฉบับที่อ้างอิง ณ วันที่
อัปเดตนี้ยังไม่ได้ถูก sync ให้รวม FR-18 เข้าฟีเจอร์ใดเลย แม้ [[backlog]] จะระบุว่าเพิ่มมาตั้งแต่
2026-09-27 — งานย่อยด้านล่างจัดวางตามเนื้อหา spec ต้นทาง
([[20260917-01-patient-ncd-history-lab-complication-risk]]) ไปพลางก่อน ควรรัน `/sync-feature-journey`
เพื่อปิดช่องว่างนี้อย่างเป็นทางการ

(2) **งานค้างเชิงพฤติกรรม (carryover, ยังไม่ใช่ task ใหม่):** โค้ดรอบนี้ของ T-3-02/T-3-03 (FR-01/FR-02)
แสดงประวัติวินิจฉัย/ผลตรวจ lab โดยอ่านข้อมูลแบบตรงชั่วคราว ระหว่างที่ส่วนฝั่งเซิร์ฟเวอร์ของระบบยังไม่พร้อม
ใช้บริการ — การเข้าถึงเหล่านี้**ยังไม่มีการบันทึกร่องรอยการเข้าถึงข้อมูล** ตามที่ T-2-07 (NFR-06) กำหนด
ไว้ตั้งแต่ Phase 2 ถือเป็นงานค้างที่ต้องปิดก่อน Phase 3 จะถือว่าสมบูรณ์ตามแผนนี้ (อธิบายเชิงพฤติกรรมเท่านั้น
ไม่ผูกกับวิธี implement ใดๆ)

| รหัส | ชื่องาน | FR/NFR ที่เกี่ยวข้อง | หมายเหตุ dependency ภายใน phase |
| --- | --- | --- | --- |
| T-3-01 | เชื่อมต่อ/จัดเตรียมแหล่งข้อมูลประวัติวินิจฉัยและผลตรวจ lab (ข้อมูลจริงจาก HOSxP หรือชุดข้อมูลจำลองระหว่างพัฒนา) ให้ระบบอ่านได้ | NFR-01 | ไม่มี — เป็นจุดเริ่มต้นของ phase |
| T-3-02 | แสดงประวัติการวินิจฉัยโรค NCD ของผู้ป่วยที่เลือกไว้ เรียงตามช่วงเวลา | FR-01 | ต่อจาก T-3-01 |
| T-3-03 | แสดงผลตรวจ lab มาตรฐานที่เกี่ยวข้องของผู้ป่วยที่เลือกไว้แบบย้อนหลังเป็นช่วงเวลา เพื่อให้ผู้ดูแลติดตามแนวโน้มได้ | FR-02 | ต่อจาก T-3-01 |
| T-3-04 | จำกัดการแสดงประวัติวินิจฉัยและผล lab เฉพาะผู้ใช้งานที่ผ่านเงื่อนไขพื้นฐานเท่านั้น (ใช้กลไกควบคุมสิทธิ์ที่สร้างไว้ใน Phase 2 — ผู้ใช้ที่ผ่านเงื่อนไขครบทุกคนดูข้อมูลผู้ป่วยทุกรายได้เท่ากัน ไม่มีการจำกัดระดับรายผู้ป่วยอีกต่อไป) | NFR-02 (บังคับใช้ซ้ำ — สร้างไว้แล้วที่ [[phase-2-patient-search-selection-data-protection-foundation-tasks|Phase 2]]) | ต่อจาก T-3-02, T-3-03 |
| T-3-05 | ผู้ใช้งานกดปุ่มบนการ์ดผู้ป่วยแต่ละรายในหน้ารายชื่อผู้ป่วย ให้ระบบหาวันที่ตรวจ HbA1c ทั้งหมดของผู้ป่วยที่อยู่ในปีงบประมาณราชการไทย (1 ตุลาคม–30 กันยายน) ที่เลือก แล้วคำนวณจำนวนครั้งที่ตรวจและระยะห่างเป็นจำนวนวันระหว่างการตรวจแต่ละครั้ง (กรณีไม่มีผลตรวจเลยให้บันทึกจำนวนครั้ง = 0 เป็นหลักฐานว่าตรวจสอบแล้ว, กรณีตรวจครั้งเดียวให้บันทึกจำนวนครั้ง = 1 โดยไม่มีค่าระยะห่าง) | FR-18 | ต่อจาก T-3-03 (ต้องมีผล lab ในระบบก่อน) |
| T-3-06 | ส่งเฉพาะตัวเลขสรุปที่คำนวณแล้วจาก T-3-05 (จำนวนครั้ง, ระยะห่างเป็นวัน) ให้บริการ AI ภายนอกเขียนสรุปเป็นภาษาคนกำกับด้วยข้อความชัดเจนว่าเป็นข้อมูลประกอบ ไม่ใช่คำแนะนำทางการแพทย์ — ห้ามส่ง HN/ชื่อผู้ป่วย/วันที่ตรวจจริง/ค่าผล HbA1c ใดๆ ให้บริการ AI เด็ดขาด หากบริการ AI ใช้งานไม่ได้/ล้มเหลว ระบบยังคงบันทึกตัวเลขสรุปจาก T-3-05 ได้ตามปกติ เพียงไม่มีข้อความสรุปภาษาคนเท่านั้น | FR-18, NFR-21 (ขยายขอบเขตจาก T-2-09 ให้ครอบคลุมข้อมูลชุดใหม่นี้ด้วย) | ต่อจาก T-3-05 |
| T-3-07 | บันทึกผลสรุป (ตัวเลขที่คำนวณ + ข้อความที่ AI เขียน + เวลาที่สร้าง) แยกเก็บรายผู้ป่วยต่อปีงบประมาณ กดปุ่มซ้ำให้เขียนทับผลเดิมของผู้ป่วย/ปีงบประมาณเดียวกัน (ไม่เก็บประวัติ) พร้อมบันทึกร่องรอยการเข้าถึงข้อมูลผล lab รายบุคคลทุกครั้งที่กดปุ่มนี้ | FR-18, NFR-06 | ต่อจาก T-3-05, T-3-06 |
