# Phase 1 — Authentication: งานย่อย

ส่วนหนึ่งของ [[release-plan]] (Phase 1) ครอบคลุม FR-07–FR-10, NFR-17, NFR-18 จาก [[backlog]] และ
[[feature-list#6. สมัครบัญชี เข้าสู่ระบบ และจัดการรหัสผ่านด้วยอีเมล (Authentication)|feature-list]]
งานย่อยด้านล่างเขียนด้วยภาษาเชิงพฤติกรรม/ผลลัพธ์เท่านั้น **ไม่ระบุเทคโนโลยีการ implement**

| รหัส | ชื่องาน | FR/NFR ที่เกี่ยวข้อง | หมายเหตุ dependency ภายใน phase |
| --- | --- | --- | --- |
| T-1-01 | ผู้ใช้งานสมัครบัญชีใหม่ด้วยตนเองโดยกรอกอีเมลและรหัสผ่าน | FR-08 | ไม่มี — เป็นจุดเริ่มต้นของ phase |
| T-1-02 | บัญชีที่สมัครใหม่อยู่ในสถานะยังใช้งานไม่ได้ (ไม่มีสิทธิ์/บทบาทใดๆ) จนกว่าผู้ดูแลระบบจะอนุมัติสิทธิ์ให้ | FR-08 | ต่อจาก T-1-01 |
| T-1-03 | บังคับให้รหัสผ่านที่ผู้ใช้ตั้งตอนสมัครมีความยาวขั้นต่ำ 8 ตัวอักษร และมีทั้งตัวอักษรและตัวเลข | NFR-17 | ต่อจาก T-1-01 (ตรวจสอบระหว่างขั้นตอนสมัคร) |
| T-1-04 | ระบบส่งอีเมลยืนยันตัวตนให้ผู้สมัครใหม่ทันทีหลังสมัครสำเร็จ | FR-09 | ต่อจาก T-1-01 |
| T-1-05 | บล็อกไม่ให้ผู้ใช้ที่ยังไม่ยืนยันอีเมลเข้าใช้งานฟีเจอร์อื่นของระบบ พร้อมแจ้งเตือนให้ยืนยันก่อน | FR-09 | ต่อจาก T-1-04 |
| T-1-06 | ผู้ใช้งานที่มีบัญชีอยู่แล้ว (ผ่านการอนุมัติและยืนยันอีเมลแล้ว) เข้าสู่ระบบด้วยอีเมลและรหัสผ่านได้สำเร็จ | FR-07 | อิสระจาก T-1-01–05 (ใช้บัญชีที่มีอยู่แล้ว) |
| T-1-07 | ผู้ใช้งานที่ลืมรหัสผ่านขอลิงก์รีเซ็ตรหัสผ่านทางอีเมล และตั้งรหัสผ่านใหม่ได้สำเร็จตามนโยบายความซับซ้อนขั้นต่ำเดียวกัน | FR-10, NFR-17 | อิสระจาก T-1-01–06 |
| T-1-08 | ทุกขั้นตอน (เข้าสู่ระบบผิดพลาด, สมัครด้วยอีเมลที่มีอยู่แล้ว, ขอรีเซ็ตรหัสผ่านด้วยอีเมลที่ไม่มีในระบบ) แสดงข้อความแจ้งเตือนแบบเดียวกันเสมอ โดยไม่เปิดเผยว่าอีเมลที่กรอกมีบัญชีอยู่ในระบบหรือไม่ | NFR-18 | ต่อจาก T-1-01, T-1-06, T-1-07 (ครอบคลุมทั้ง 3 ขั้นตอน) |
