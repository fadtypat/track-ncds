# Phase 2 — ค้นหา/เลือกผู้ป่วย + การป้องกันข้อมูลพื้นฐาน: งานย่อย

ส่วนหนึ่งของ [[release-plan]] (Phase 2) ครอบคลุม FR-05, FR-06, NFR-02, NFR-03, NFR-04, NFR-06 จาก
[[backlog]] รวมส่วนพื้นฐานของ [[feature-list#3. ค้นหา/เลือกผู้ป่วยในความดูแล|feature-list ฟีเจอร์ที่ 3]]
และส่วนพื้นฐานของ [[feature-list#4. คุ้มครองข้อมูลส่วนบุคคลของผู้ป่วยตาม PDPA|feature-list ฟีเจอร์ที่ 4]]
งานย่อยด้านล่างเขียนด้วยภาษาเชิงพฤติกรรม/ผลลัพธ์เท่านั้น **ไม่ระบุเทคโนโลยีการ implement**
ต้องเริ่มหลัง [[phase-1-authentication-tasks|Phase 1]] เสร็จสมบูรณ์ (ผู้ใช้งานต้องเข้าสู่ระบบและยืนยัน
อีเมลสำเร็จก่อนจึงจะเริ่ม journey นี้ได้) **รวมถึง T-1-12 (FR-14 มอบหมายผู้ป่วย) ต้องเสร็จก่อนด้วยเสมอ**
เพราะ T-2-01 ด้านล่างต้องมี PatientAssignment อยู่จริงในระบบก่อนจึงจะมีรายชื่อผู้ป่วยให้แสดง (อัปเดต
2026-09-24 รอบสอง)

| รหัส | ชื่องาน | FR/NFR ที่เกี่ยวข้อง | หมายเหตุ dependency ภายใน phase |
| --- | --- | --- | --- |
| T-2-01 | แพทย์/พยาบาลเรียกดูรายชื่อผู้ป่วย NCD ทั้งหมดที่อยู่ในความดูแลของตนเอง | FR-05 | ไม่มี — เป็นจุดเริ่มต้นของ phase |
| T-2-02 | ค้นหาผู้ป่วยเฉพาะรายด้วยเลขประจำตัวผู้ป่วย (HN) รูปแบบตัวเลขล้วน 7 หลัก | FR-06 | ต่อจาก T-2-01 |
| T-2-03 | แจ้งเตือนผู้ใช้เมื่อกรอก HN ไม่ครบ 7 หลัก หรือค้นหาด้วย HN ที่ครบ 7 หลักแล้วแต่ไม่พบผู้ป่วยที่ตรงกัน (ตรวจหลังกดค้นหาเท่านั้น) โดยให้กรอกค้นหาใหม่ได้ทันทีและไม่บล็อกการเรียกดูรายชื่อทั้งหมด | FR-06 | ต่อจาก T-2-02 |
| T-2-04 | จำกัดไม่ให้ผู้ใช้งานเห็น/เข้าถึงผู้ป่วยรายใดที่ไม่ได้อยู่ในความดูแลของตนเอง (assignment ระดับรายผู้ป่วย ไม่ใช่ตามแผนก/หน่วยงาน) | NFR-02 | ต่อจาก T-2-01 |
| T-2-05 | จำกัดการประมวลผลข้อมูลผู้ป่วยเฉพาะเท่าที่จำเป็นต่อวัตถุประสงค์การดูแลรักษาเท่านั้น ในทุกจุดที่ระบบเข้าถึงข้อมูลผู้ป่วย | NFR-03 | ต่อจาก T-2-01, T-2-04 |
| T-2-06 | เข้ารหัสข้อมูลผู้ป่วยทั้งขณะจัดเก็บและขณะส่งผ่านเครือข่ายในทุกจุดที่ข้อมูลผู้ป่วยไหลผ่าน | NFR-04 | ต่อจาก T-2-01 |
| T-2-07 | บันทึกร่องรอยการเข้าถึงข้อมูลผู้ป่วย (ใครเข้าถึง/เมื่อไร/ข้อมูลใด) ทุกครั้งแบบไม่มีการยกเว้น แม้การบันทึกจะล้มเหลวก็ต้องไม่ปล่อยให้เข้าถึงข้อมูลได้โดยไม่มีร่องรอย (fail-safe) | NFR-06 | ต่อจาก T-2-04 |
