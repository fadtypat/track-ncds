# Test Cases — วิเคราะห์และแจ้งเตือนความเสี่ยงโรคแทรกซ้อน

Test case แบบ step-by-step ของฟีเจอร์
[[../../../02-design/feature-list#2. วิเคราะห์และแจ้งเตือนความเสี่ยงโรคแทรกซ้อน|2. วิเคราะห์และแจ้งเตือนความเสี่ยงโรคแทรกซ้อน]]
(FR-03, FR-04, NFR-01, NFR-02) อ้างอิงเกณฑ์ยอมรับจาก
[[../acceptance-criteria#2. วิเคราะห์และแจ้งเตือนความเสี่ยงโรคแทรกซ้อน|acceptance-criteria]] และ happy
path จาก [[../../../02-design/user-journey|user-journey]] ขั้นตอนที่ 12–13 ใช้หน้าจอ
`patient-detail-risk-found.html` (แขนง "พบ") และ `patient-detail-no-risk.html` (แขนง "ไม่พบ") จาก
[[../../../02-design/01-prototypes/20260918-01-v1/prototype|prototype v1]] เป็นตัวอย่างอ้างอิง

**Precondition ร่วมของทุก test case ในไฟล์นี้:** ผ่านฟีเจอร์
[[patient-search-selection|ค้นหา/เลือกผู้ป่วยในความดูแล]] มาก่อนแล้ว (เลือกผู้ป่วยรายบุคคลแล้ว) —
โดยทั่วไปเกิดต่อเนื่องจากการดูข้อมูลใน
[[patient-ncd-diagnosis-lab-history|ดูประวัติการวินิจฉัยและผลตรวจ lab]] ตามลำดับใน user-journey

หมายเหตุ Test Data: ค่าตัวเลข threshold ของ lab จริงที่ใช้ตัดสิน rule ยังไม่ถูกกำหนดในระดับ spec/
detailed-design ([[../test-plan#นอกขอบเขต (Out of scope)|นอกขอบเขตการทดสอบตาม test-plan]]) ค่าตัวอย่าง
ด้านล่างจึงเป็นค่าจำลอง (mock) ที่ทีมทดสอบ config ไว้ในสภาพแวดล้อมทดสอบเพื่อยืนยัน "ลำดับการประมวลผล
เชิงตรรกะ" ของ Risk Rule Engine เท่านั้น ไม่ใช่ค่าที่มีนัยทางคลินิกจริง

บทบาทผู้ทดสอบ: แพทย์/พยาบาลผู้ดูแลผู้ป่วย NCD (บทบาทเดียวในขอบเขตของระบบ)
