**อัปเดต 2026-09-25 (ยกเลิก PatientAssignment ทั้งระบบ — ยืนยันแล้วโดยผู้ใช้):** เปลี่ยนชื่อไฟล์/หัวข้อ
จาก "จัดการบัญชีผู้ใช้งาน สิทธิ์ และการมอบหมายผู้ป่วย (Admin)" เป็น "จัดการบัญชีผู้ใช้งานและสิทธิ์
(Admin)" ลบ test case ของ FR-14 (เดิม TC-07-11–TC-07-14 "มอบหมาย/ยกเลิกมอบหมายผู้ป่วย") ออกทั้งหมด
เพราะ FR-14 ถูกยกเลิก (ไม่มีกลไก PatientAssignment ให้จัดการอีกต่อไป) เลข TC ที่เหลือถูกเรียงใหม่ต่อเนื่อง
(เดิม TC-07-15–TC-07-23 กลายเป็น TC-07-11–TC-07-19) ข้อความ/แถวเดิมอยู่ใน git history

**Precondition ร่วมของทุก test case ในไฟล์นี้ (เว้นแต่ระบุไว้เป็นอย่างอื่น):** ผู้ทดสอบเข้าสู่ระบบสำเร็จ
ด้วยบัญชีที่มี `role = admin` และ `isActive = true` ผ่านกลไกเดียวกับแพทย์/พยาบาลตาม
[[user-authentication-email-password|FR-07]] มาก่อนแล้ว (บัญชี admin คนแรกสร้างผ่าน Firebase Console/
Firestore โดยตรงในสภาพแวดล้อมทดสอบ ตามที่ FR-11–FR-15 ระบุว่าการ bootstrap admin คนแรกอยู่นอกขอบเขต
ของฟีเจอร์นี้เอง)

บทบาทผู้ทดสอบ: Admin (ผู้ดูแลระบบ) เป็นหลัก และบัญชีแพทย์/พยาบาลเพิ่มเติมสำหรับกรณี guard/negative
(ยืนยันว่าไม่ได้รับสิทธิ์แก้ไข FR-16 ที่เป็นของแพทย์/พยาบาลเท่านั้น ไม่ใช่ของ admin)
